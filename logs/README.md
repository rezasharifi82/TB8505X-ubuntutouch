# Engineering Logs & Diagnostic Traces

This directory contains sanitized engineering records, build reports, and test results:

- Build logs from kernel compilation.
- Verification checksum logs.
- Test logs from host environment checks.

> **Privacy Rule:** Any logs containing physical device serial numbers, IMEI, Wi-Fi/BT MAC addresses, or raw private tokens MUST be sanitized or excluded before committing. Local `*.log` files are automatically excluded by `.gitignore`.
