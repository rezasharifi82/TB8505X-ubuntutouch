### Verified Overlay Contents:
1. **GPU & Hardware Udev Rules ([`70-akita.rules`](file:///home/mreza/Desktop/TB8505X/TB8505X-ubuntutouch/overlay/system/usr/lib/udev/rules.d/70-akita.rules)):**
   - Grants `0666` permissions to `/dev/pvrsrvkm` and `/dev/pvr_sync` for PowerVR GE8300 userspace driver access.
   - Grants permissions to `/dev/ion`, `/dev/sw_sync`, and `/dev/sync`.
   - Creates symlinks and sets permissions for `/dev/binder`, `/dev/hwbinder`, and `/dev/vndbinder`.
2. **Audio Routing ([`arm_droid_card_custom.pa`](file:///home/mreza/Desktop/TB8505X/TB8505X-ubuntutouch/overlay/system/etc/pulse/arm_droid_card_custom.pa)):**
   - `load-module module-droid-card rate=48000 quirks=+no_hw_volume voice_virtual_stream=true`
3. **IPC Configuration ([`gbinder.conf`](file:///home/mreza/Desktop/TB8505X/TB8505X-ubuntutouch/overlay/system/etc/gbinder.conf)):**
   - API level locked to `29` (Android 10) for `/dev/binder`, `/dev/hwbinder`, `/dev/vndbinder`.
4. **Android Init Stubs:**
   - Overrides `keystore` and `wait_for_keymaster` to `disabled` so the Halium LXC container does not block waiting for Beanpod trustlets.
5. **Monolithic Module Override:**
   - `.halium-override-dir` in `lib/modules/` signals the rootfs overlay store to bind-mount the empty directory, preventing out-of-tree module conflicts.
